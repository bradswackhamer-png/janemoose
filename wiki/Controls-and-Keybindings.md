# 🎮 Controls & Keybindings

All tractor and implement actions can be rebound in Minecraft's **Options > Controls > Key Binds** menu under the **Jane Moose Machinery** category.

---

## ⌨️ Default Keybindings

| Action | Default Key | Context | Description |
| :--- | :---: | :---: | :--- |
| **Drive / Steer** | `W / A / S / D` | Riding | Throttle forward/reverse, steer left/right. |
| **Dismount** | `Left Shift` | Riding | Dismount from tractor seat. |
| **Toggle Headlights** | `[L]` | Riding / GUI | Turn front high-beam headlights **ON / OFF**. |
| **Lift / Lower Implement** | `[H]` or `Space` | Riding / GUI | Toggle implement between **Transport** and **Working** positions. |
| **Toggle Implement Power** | `[X]` | Riding / GUI | Turn implement active PTO mechanism **ON / OFF**. |
| **Open Tractor Dashboard** | `[C]` | Riding / Stand | Open fuel gauge, stats, rename field, and light switch. |
| **Place Implement** | `Right-Click` | Handheld | Deploy 3D implement entity onto the ground. |
| **Hitch Implement** | Reverse near | Driving | Reverse tractor to implement drawbar to hitch automatically. |
| **Unhitch Implement** | `Shift + Right-Click` | Outside | Detach hitched implement using wrench or empty hand. |
| **Pack Up Tractor** | `Shift + Right-Click` | Outside (Wrench) | Retrieve tractor and attachments into inventory item form. |
